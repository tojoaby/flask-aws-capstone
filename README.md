# Flask Application on AWS EC2

## Project Overview
This project demonstrates the deployment of a Flask web application on an Amazon EC2 instance.

## Technologies Used
- Python
- Flask
- Amazon EC2
- Git
- GitHub

## Deployment
The Flask application is hosted on an AWS EC2 instance and is accessible through port 5000.
